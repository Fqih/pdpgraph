# PDPGraph + Tierline

Grounded, clause-cited compliance intelligence for Indonesia's Personal Data Protection Law
(UU No. 27 Tahun 2022), running on a cost-aware, policy-enforcing multi-tier LLM gateway.

**Status:** early development (Phase 0, foundations). No evaluation results yet; this README
will only report numbers produced by runs in this repository.

> **Not legal advice.** PDPGraph is an engineering and research project. Its outputs are not legal
> advice and do not certify compliance.
